SmartQueue: Public Office Appointment & Token System

A high-reliability digital queue management platform created for government administration departments (Revenue, Certification, and Document Registration). Replaces chaotic physical lines with automated appointment slotting, authenticated token dispensing, and synchronized officer desks.

  • Fraud-Proof Token Verification: Issues unique booking references paired with dynamic 4-digit OTPs checked via secure MySQL prepared statements.
  • Strict Time-Window Enforcement: Algorithm enforces a 10-minute early check-in buffer up to a 30-minute late expiration cutoff, preventing stale queues.
  • Real-Time Asynchronous Updates: Uses AJAX polling (currentstatus.js & get_stats.php) for live queue dashboards without page refresh.
  • Multi-Role Workspace: Dedicated views for Citizens (booking & status), Department Officers (queue calling & session tracking), and Admins (department stats).

DocuTwin AI: Document Duplicate Finder & NLP Clustering

An intelligent text analytics and duplicate discovery system designed to process institutional repositories. Leverages natural language processing vector spaces to detect plagiarized content, group near-duplicate clusters, and perform automated differential vocabulary analysis.

  • TF-IDF & Cosine Similarity Engine: Transforms raw text into high-dimensional vector spaces using Scikit-Learn to compute exact pairwise similarity percentages.
  • Graph-Based Document Clustering: Utilizes NetworkX to model document connectivity and automatically group clusters exceeding threshold cutoffs.
  • Differential Vocabulary Analyzer: Built proprietary get_missing_content logic isolating unique words between revisions.
  • Batch Upload & Smart Merging: Handles multi-file uploads with automated file concatenation and integrated speech-recognition voice commands.
